# Employee Attrition Analysis using PySpark & Databricks

This project analyzes employee attrition data using PySpark in Databricks.

## Analysis Performed
- Attrition by City
- Attrition by Education
- Attrition by Gender
- Visualizations using matplotlib

## Tools Used
- Databricks (PySpark)
- Python
- Matplotlib
- GitHub

## Dataset Columns
Education, JoiningYear, City, PaymentTier, Age, Gender, EverBenched, ExperienceCurrentDomain, LeaveOrNot
